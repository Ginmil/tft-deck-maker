# 롤토체스 덱 메이커

시너지·아이템·상징을 입력하면 최적의 덱을 자동으로 찾아주는 웹앱.

| 기능 | 입력 | 결과 |
|---|---|---|
| **상징 팀 메이커 (핵심)** | 가진 상징 (+ 추가 목표 시너지) | 상징으로 닿을 수 있는 시너지 단계를 모두 탐색해 추천 팀, 상징을 줄 챔피언까지 표시 |
| 시너지로 찾기 | 원하는 시너지와 목표 단계 | 조건을 만족하는 덱 상위 5개 |
| 아이템으로 찾기 | 가진 완성 아이템 | 아이템을 가장 잘 쓰는 캐리 3명 + 각 캐리 중심 덱 + 아이템 배분 |

## 실행 방법

`index.html` 을 더블클릭하면 브라우저(크롬·엣지)에서 바로 열립니다.
처음 열면 Community Dragon에서 현재 시즌 데이터를 자동으로 받아옵니다.

인터넷이 안 될 때는 "샘플 데이터 (테스트용)" 버튼으로 가상 세트를 불러와 동작을 확인할 수 있습니다.

> 코드를 수정했다면 `node build.mjs` 를 실행해 `js/bundle.js` 를 다시 만들어야 화면에 반영됩니다.

## 시즌이 바뀌면?

1. **보통은 아무것도 안 해도 됨** — 기본 URL이 `latest`라 새 패치/시즌 데이터가 자동으로 들어옵니다. 앱에서 "불러오기"만 다시 누르세요.
2. **PBE(다음 시즌 미리보기)** — URL을 `https://raw.communitydragon.org/pbe/cdragon/tft/ko_kr.json`으로 바꾸고 불러오기.
3. **특정 패치 고정** — `latest` 자리에 Community Dragon 사이트에 있는 패치 폴더 이름을 넣으면 그 시점 데이터.
4. **데이터 형식 자체가 바뀌거나 다른 API를 쓰고 싶을 때** — `js/adapters/` 에 새 어댑터를 만들고 아래 공통 형식만 맞춰 주면, 엔진과 화면은 고칠 필요가 없습니다.

```js
{
  set:       { key, number, name },
  traits:    { [id]: { id, name, breakpoints: [2,4,6], desc } },
  champions: [ { id, name, cost, traits: [traitId], role, icon } ],  // role: AD | AP | TANK | FIGHTER | FLEX
  items:     [ { id, name, role, icon } ],
  emblems:   [ { id, name, trait, icon } ]
}
```

## 알고리즘 요약

**왜 탐색이 필요한가** — 챔피언 약 60명 중 8명을 고르는 경우의 수는 수십억 개라 전부 계산할 수 없습니다.

**빔 서치 (`search.js`)** — 빈 팀에서 시작해 챔피언을 한 명씩 추가하고, 매 단계마다 점수 상위 K개(기본 200개) 조합만 남깁니다. 중간 단계에서는 "목표 시너지에 얼마나 가까워졌는지"도 점수에 넣어, 아직 단계가 안 열렸지만 유망한 조합이 버려지지 않게 합니다. 마지막에 서로 2명 이상 다른 덱만 골라 비슷한 결과의 반복을 막습니다.

**상징 배정 (`scorer.js` → `assignEmblems`)** — 상징은 그 시너지가 *없는* 챔피언에게만 의미가 있고, 챔피언당 아이템은 3칸입니다. 백트래킹으로 적용 가능한 상징 수를 최대화하며, 캐리는 아이템 칸을 비워두기 위해 가급적 상징을 주지 않습니다.

**상징 팀 메이커 (`emblemTeamMaker`)** — 상징별로 `목표 단계 − 상징 수 ≤ 그 시너지 챔피언 수`인 단계를 모두 후보 목표로 만들고(챔피언만으로는 불가능한 "상징 전용" 단계 포함), 각각 빔 서치를 돌린 뒤 합쳐서 순위를 매깁니다.

**점수 함수** — 발동된 시너지 단계(높을수록 가중), 넘친 인원과 발동 못 한 시너지에는 감점, 목표 시너지 달성 보너스, 코스트 합(전투력 대용).

## 통계 가중치 (실제 경기 승률 반영)

라이엇 공식 API로 상위 랭커 경기를 모아, 시너지 단계별 평균 등수로 점수에 가중치를 줍니다.

1. [developer.riotgames.com](https://developer.riotgames.com)에서 개발용 API 키 받기 (24시간마다 만료)
2. `tools/config.example.json` 을 복사해 `tools/config.json` 으로 저장하고 `apiKey` 에 키 넣기
3. `collect-stats.bat` 더블클릭 (또는 `node tools/collect-stats.mjs`) — Node.js 18 이상 필요
4. 끝나면 `data/weights.json`, `data/weights.js` 가 생기고, `index.html` 을 새로고침하면 자동 반영

- 기본 설정(플레이어 60명 × 최근 10경기)으로 약 10~15분. 받은 경기는 `tools/cache/` 에 저장돼 다시 실행하면 이어서 진행
- 가중치 = 1 + (4.5 − 평균 등수) × 0.35 (0.5~1.6 범위). 표본이 적은 단계는 평균값 쪽으로 보정
- 화면 상단의 체크박스로 가중치를 켜고 끌 수 있고, 시너지 옆에 실제 평균 등수가 표시됨
- **API 키는 `config.json` 에만 넣고 다른 사람과 공유하거나 깃허브에 올리지 마세요** (`.gitignore` 에 포함됨)
- 한계: 평균 등수는 상관관계라, 시너지 자체가 강한지 같이 쓰는 캐리가 강한지는 구분하지 못함

### 상징 배정 · 핵심 캐릭터

- **상징을 누구에게?** 수집한 경기에서 상위권 플레이어가 그 상징을 어떤 챔피언에게 꼈는지 비율을 보고 그대로 따라감. 통계가 없으면 그 시너지 구성원과 역할·사거리가 비슷하고 코스트가 높은 챔피언을 우선 (`js/engine/roles.js`)
- 상징 태그에 마우스를 올리면 배정 이유가 표시됨
- **핵심 캐리**: 실제 경기에서 완성 아이템 3개를 든 비율(캐리율)이 높고 비싼 후방 딜러. **메인 탱커**: 가장 비싼 탱커/전사
- 한 챔피언에 상징은 2개까지, 핵심 캐리는 아이템 자리 때문에 1개까지
- 상징 어울림은 ① 전방/후방 ② 물리/마법(마법사에게 공속 상징 X) ③ 사거리 ④ 코스트 순으로 판단. 어울리는 챔피언이 없어 억지로 낀 상징은 빨간색으로 표시하고 그 덱은 감점

### 챔피언 역할 (물리/마법/탱커)

- 기본: 스킬 설명의 피해 유형(물리/마법) + 사거리 + 마나로 추정. 근접이면서 마나 50 이하·방어 계수 없음 → 근접 딜러(암살자), 마나 80 이상이거나 방어·체력 계수 → 탱커
- 통계가 있으면: 상위권 경기에서 그 챔피언이 실제로 든 아이템(물리/마법/탱커 아이템 비율)으로 보정 — 카드에 `✓` 표시, 마우스를 올리면 비율 표시

### 배치툴

- 4×7 육각형 보드에 챔피언을 끌어다 놓기(또는 클릭 → 탱커·근접은 앞줄, 원거리는 뒷줄 빈자리에 자동), 칸끼리 끌어서 이동, 우클릭 또는 아래 칸으로 끌어서 빼기
- 아이템: 일반 / 찬란한 / 유물 / 상징 탭으로 분류 (검색은 전체에서). 챔피언 위로 끌어 놓기 / 아이템 클릭 후 챔피언 클릭 (최대 3개)
- 챔피언 클릭 → 아래 상세 패널에서 별 변경, 아이템 ✕로 빼기, 챔피언 빼기
- 챔피언이나 낀 아이템을 **보드 밖으로 끌어내면 빠짐**, 낀 아이템을 다른 챔피언에게 끌면 옮겨짐
- 아이템·상징에 마우스를 올리면 조합식(재료 2개) 표시 — 배치툴, 덱 결과, 3신기, 아이템/상징 선택 화면 공통. 조합 불가 아이템(증강 상징·유물·찬란한)은 획득 방법 안내
- 별(★) 클릭으로 1~3성, 시너지는 실시간 계산 (화신 2명분, 상징 효과 반영)
- 모든 덱 결과의 **"배치툴로 보기"** → 아이템·상징·3성까지 채워서 자동 배치 (경기 데이터에 위치 정보가 없어 규칙으로 배치: 메인 탱커 앞줄 가운데, 핵심 캐리 뒷줄 구석)
- 저장(브라우저에 50개까지), 배치 코드 복사/붙여넣기로 공유, 주소 끝 `#b=코드` 로도 열림
- 코드: `js/builder.js`

### 메타 덱 (랭커 통계 덱)

- 수집한 랭커 경기의 **최종 덱**을 "주력 시너지(가장 많이 모은 시너지) + 핵심 캐리"로 묶음
- 핵심 캐리: 딜 아이템(탱커 아이템 제외)을 가장 많이 든 챔피언 → 같으면 별(3성) 많은 쪽 → 같으면 코스트. 덱 화면의 핵심/탱커는 그 덱 전체에서 랭커들이 딜템/탱템을 가장 많이 준 챔피언
- 구성은 자주 쓰인 순으로 **레벨만큼 자리를 채우고**, 절반 미만으로 쓰인 자리는 점선 + "선택 %"로 표시
- 3성 완성 비율이 높은 챔피언은 ★★★, 3코스트 이하가 절반 이상 3성이면 "3성작" 태그
- 덱별 판수 · 평균 등수 · 순방률 · 1등률 · 픽률 · 평균 레벨, 그 덱에서의 핵심 캐리·메인 탱커 3신기
- 티어: 판수 보정한 평균 등수 기준 S(3.7등 이하) / A(4.0) / B(4.3) / C
- 정렬(평균 등수/픽률/1등률)과 최소 판수(8~50판) 선택 가능
- 한계: 같은 캐리라도 시너지 구성이 다르면 다른 덱으로 나뉘고, 8판 미만 덱은 표시하지 않음

### 챔피언 3신기 (추천 아이템)

- "챔피언 3신기" 탭: 상위권 경기에서 각 챔피언이 실제로 든 아이템 3개 조합 중 많이 쓰이면서(전체의 5% 또는 3판 이상) 평균 등수가 좋은 조합 최대 3개
- 판수가 적은 조합은 평균(4.5등) 쪽으로 보정(15판 분량)해서 우연히 몇 판 1등한 조합이 위로 오지 않게 함. 15판 미만은 "표본 적음" 표시
- 도적의 장갑을 낀 챔피언은 나머지 아이템이 랜덤이라 3신기·역할 통계에서 제외, 전략가 아이템(왕관/망토/방패)이 낀 조합도 3신기에서 제외
- 덱 결과에도 핵심 캐리·메인 탱커의 추천 3신기가 표시됨

### 덱 구성 옵션

- **5코스트**: 덱에 넣을 5코스트 최대 수 (기본 2개까지). "안 씀"으로 3·4코스트 중심 덱 탐색
- **특수 기물**: 형태가 여러 개라 원하는 걸 뽑기 어려운 기물(Set 18: 럭스). 기본은 있는 덱과 없는 덱을 번갈아 보여줌. 데이터의 "중첩 2개로 간주" 규칙으로 자동 감지

## 시즌 특수 규칙

시너지 설명 문장을 읽어서 특수 규칙을 자동으로 반영합니다 (`cdragon.js` → `applySpecialRules`).

- "중첩이 2개로 간주" → 그 챔피언의 시너지를 2명분으로 셈 (Set 18: 화신 럭스 — 예: 검은 가시 럭스 = 검은 가시 2)
- "N개의 팀 슬롯" → 팀 자리를 N칸 차지 (Set 18: 장로 드래곤)
- "OO 특성을 +N" → OO 시너지를 N명분으로 셈

상징을 껴도 시너지 단계가 오르지 않으면(예: 이미 6인데 7이 되는 경우) "상징 n개는 단계를 못 올림"으로 표시하고 감점합니다.

## 한계와 개선 아이디어

- 챔피언 역할(물리/마법/탱커)은 데이터의 `role` 필드로 추정, 없으면 스탯으로 대략 판단
- 아이템 역할은 아이템 스탯(공격력·주문력·방어 등)으로 자동 분류
- 시즌 고유 메커니즘(특수 증강, 변신 유닛 등)은 반영하지 않음
- 더 정확한 최적해가 필요하면 정수 선형 계획법(ILP)으로 교체 가능 (`searchTeams`만 바꾸면 됨)
